TASK C4: Access the service
-----------------------------
Command:
  kubectl port-forward service/lab3-web-svc 8080:80

Command:
  curl http://localhost:8080/

Output:
  Hello from Lab 3

Command:
  curl http://localhost:8080/health

Output:
  ok

Observation:
  Both endpoints responded correctly.
  Traffic was forwarded from port 8080 to the service
  which load balanced across all 3 running pods.
