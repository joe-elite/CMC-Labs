TASK E3: Observe container process restart
-------------------------------------------
Command:
  kubectl exec -it lab3-web-probe-5db74dcbc7-6drv7 -- /bin/sh -c "kill 1"

Observation:
  The python:3.12-slim image does not include ps command.
  kill -9 1 on PID 1 inside a container is blocked by the
  kernel as a security measure to prevent accidental
  container termination from within.

  The liveness probe is the correct mechanism to trigger
  a container restart in Kubernetes. If the /health endpoint
  stops responding, Kubernetes will automatically restart
  the container after 3 consecutive failures (30 seconds).

  This is the intended self-healing behavior:
  - Liveness probe fails 3 times
  - Kubernetes restarts the container in place
  - RESTARTS counter increments by 1
  - Same pod, new container process
