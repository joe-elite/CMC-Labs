TASK A2: Compare host and container PIDs
----------------------------------------
Command on host:
  docker ps
  docker inspect nsdemo --format "{{.State.Pid}}"

Output:
  Container ID: 0e8154a8e216
  Host PID of container main process: 22342

Command on host:
  ps -fp 22342

Output:
  UID        PID   PPID  C STIME TTY    TIME CMD
  root     22342  22319  0 17:38 pts/0  00:00:00 bash

Observation:
  Inside container: bash is PID 1
  On host:          same bash process is PID 22342
  This proves PID namespace isolation is working.
  The container has its own PID namespace starting from 1.

TASK A3: Resource limits with cgroups
----------------------------------------
Command:
  docker run --rm -it --cpus="0.5" --memory="256m" ubuntu:22.04 bash

Inside container:
  apt-get update && apt-get install -y stress
  stress --cpu 2 --vm 1 --vm-bytes 220M --timeout 30

Docker stats observed during stress test:
  CONTAINER ID   NAME           CPU %    MEM USAGE / LIMIT    MEM %
  981233cb3f08   thirsty_wiles  50.18%   223.3MiB / 256MiB   87.22%

Observation:
  CPU capped at exactly 50% (0.5 CPUs as configured).
  Memory usage hit 223.3MiB but hard limited at 256MiB.
  cgroups enforced both limits perfectly.
