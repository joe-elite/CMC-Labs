TASK B3: Build the multistage image
-------------------------------------
Command:
  docker build -f Dockerfile.multistage -t lab3-multi .

Output:
  [+] Building 10.0s (12/12) FINISHED
  => [builder 1/4] FROM docker.io/library/python:3.12-slim  CACHED
  => [builder 2/4] WORKDIR /build
  => [builder 3/4] COPY requirements.txt .
  => [builder 4/4] RUN pip install --prefix=/install -r requirements.txt
  => [stage-1 3/4] COPY --from=builder /install /usr/local
  => [stage-1 4/4] COPY app.py .
  => naming to docker.io/library/lab3-multi:latest

Command:
  docker history lab3-multi

Output:
  IMAGE          CREATED        CREATED BY                          SIZE
  d66f9b5dc98d   34 sec ago     CMD ["python" "app.py"]             0B
  <missing>      34 sec ago     EXPOSE [5000/tcp]                   0B
  <missing>      34 sec ago     COPY app.py . # buildkit            12.3kB
  <missing>      34 sec ago     COPY /install /usr/local # buildkit 5.51MB
  <missing>      1 min ago      WORKDIR /app                        8.19kB
  <missing>      4 days ago     CMD ["python3"]                     0B
  <missing>      4 days ago     RUN set -eux; for src in idle3...   16.4kB
  <missing>      4 days ago     RUN set -eux; savedAptMark=...      41.3MB
  <missing>      5 days ago     debian.sh --arch amd64              87.4MB

Observation:
  COPY --from=builder layer is only 5.51MB vs 16.5MB in basic.
  The builder stage is completely discarded from final image.
  Only the compiled packages are copied, not the build tools.
