PART G: Functional Testing
---------------------------
Command:
  curl http://localhost:5001/health

Output:
  {"service":"product-service","status":"up"}

Command:
  curl http://localhost:5001/products/1

Output:
  {"id":1,"name":"Laptop","price":1200}

Command:
  curl http://localhost:5001/products/99

Output:
  {"error":"Product not found"}

Command:
  curl -X POST http://localhost:5002/orders \
  -H "Content-Type: application/json" \
  -d '{"product_id": 1, "quantity": 2}'

Output:
  {"message":"Order created","product":"Laptop","quantity":2,"total_price":2400}

Observation:
  product-service returned correct product data.
  order-service successfully called product-service,
  calculated total price (1200 x 2 = 2400) and returned
  a complete order response.

PART H: Failure Injection and Resilience
------------------------------------------
Command:
  docker stop product-service

Output:
  product-service

Command:
  curl -X POST http://localhost:5002/orders \
  -H "Content-Type: application/json" \
  -d '{"product_id": 2, "quantity": 1}'

Output:
  {"error":"product-service unavailable"}

Observation:
  order-service tried to contact product-service.
  fetch_product() retried 2 times with 1 second delay.
  After all retries exhausted, returned HTTP 503.
  Service degraded gracefully instead of crashing.

Command:
  docker start product-service

Output:
  product-service

Command:
  docker compose ps

Output:
  NAME             STATUS
  order-service    Up (healthy)
  product-service  Up (health: starting) -> (healthy)

Command:
  curl -X POST http://localhost:5002/orders \
  -H "Content-Type: application/json" \
  -d '{"product_id": 2, "quantity": 1}'

Output:
  {"message":"Order created","product":"Phone","quantity":1,"total_price":650}

Observation:
  product-service recovered automatically after restart.
  order-service resumed normal operation immediately.
  No manual reconfiguration was needed.
